交互 · 第 1 级

CSS + 原生 JS

什么时候用：悬停、过渡、位移这类单点效果，写好前后样式就行，不值得引库。

不满意查什么：transition 的时长与缓动曲线，以及 transform-origin 对不对。

免费 · 零依赖

交互 · 第 2 级

Motion

什么时候用：卡片增删、排序、展开收起这类布局变化，它自己算位置。

不满意查什么：layout 动画的 spring 参数，和 layoutId 有没有复用。

交互 · 第 3 级

GSAP + ScrollTrigger

什么时候用：多个动作排在同一条时间线，或动画要跟着滚动走。

不满意查什么：时间线的先后顺序、每个 tween 的起点，以及 trigger 的 start/end。

2025 年后含插件全免费 · 演示为示意

画面 · 2D

Canvas

什么时候用：一堆图或文字叠层、换图转视角，本质是画到一张布上。

不满意查什么：分层顺序、每层的缩放与位移，以及重绘是否每帧都在跑。

免费 · 原生 API

文档 ↗

画面 · 3D

Three.js

什么时候用：要自由换视角、打灯、物体真的翻折，而不是放一张图假装立体。

不满意查什么：物体有没有跟着面一起转、遮挡关系对不对、灯光位置对不对。

开源 · 演示为 CSS 3D 示意（透视 + 逐面受光）

GitHub ↗

成片

Remotion

什么时候用：口播卡、片头、需要反复复用的视频模板，用代码排每一帧。

不满意查什么：元素在第几帧出现、持续几帧，以及换内容后时长有没有对齐。

个人免费 · 演示为示意，非真实渲染

GitHub ↗

动效 · 第 2 级

Anime.js

什么时候用：多元素错峰出现的编排，一条 timeline 排完，不用手写一堆 delay。

不满意查什么：timeline 的偏移、easing 曲线，以及 stagger 的起点与方向。

开源 · 个人免费

GitHub ↗

过渡 · 第 1 级

Tween.js

什么时候用：给物体属性做数值补间，位置、颜色、进度都能过渡，比写关键帧自由。

不满意查什么：补间的对象是不是同一个引用，onUpdate 里有没有反复新建对象。

开源 · 个人免费

GitHub ↗

三维 · 第 3 级

Ammo.js

什么时候用：要真的物理——碰撞、重力、堆叠，不是靠缓动假装。

不满意查什么：重力步长固定 1/60、碰撞体形状与模型缩放有没有对齐。

开源 · 个人免费

GitHub ↗

纹理 · 第 3 级

TSL Textures

什么时候用：程序化生成表面质感，省掉贴图文件和 UV 那堆麻烦。

不满意查什么：节点接线的坐标系、颜色空间，以及噪声的缩放假象。

开源 · 随 Three.js

GitHub ↗

声音 · 第 3 级

SuperCollider

什么时候用：程序化合成音效与环境声，比塞一堆音频文件轻得多。

不满意查什么：采样率、buffer 有没有释放，包络的起落时长。

开源 · GPL

制片 · 第 3 级

FFmpeg

什么时候用：拼接、转码、抽帧、压字幕这些离线处理，脚本里跑最稳。

不满意查什么：crf 与 preset 取值，时间基与帧率有没有对齐。
